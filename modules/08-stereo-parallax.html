Stereo Vision and Parallax in Aerial Photogrammetry

Two overlapping vertical aerial photographs observe the same ground point from different camera positions. The horizontal image shift — x-parallax — carries depth information and is the foundation of stereoscopic height measurement.

What the stereo pair is saying

Left image coordinate

xL,t=f(X+B2)H−h
The left camera sees the top of the vertical object relative to its own exposure station.

Right image coordinate

xR,t=f(X−B2)H−h
The right camera sees the same top point shifted along the epipolar direction.

Top and bottom absolute parallax

Pt=xL,t−xR,tPb=xL,b−xR,b
You need both absolute parallaxes: one for the top of the vertical object and one for the bottom/base point. In this page, the symbol Pb means the base-point absolute parallax.

Differential parallax

dP=Pt−Pb
This is the standard photogrammetric definition for a vertical object: dP is the difference between the top absolute parallax and the bottom absolute parallax.

Height from parallax differences

h=H·dPPb+dP
Because the top absolute parallax equals Pb + dP = Pt, the object height can be estimated directly from the flight height H, the base-point parallax Pb, and the differential parallax dP.

Parallax properties

1. Higher point → larger pAs h increases, H−h becomes smaller, so the same point shifts farther apart in the two photographs.
2. Larger air base → larger pA wider camera separation increases the stereo viewing angle and strengthens depth sensitivity.
3. Higher flight → smaller pAt greater H, the scene is farther away and the parallax signal becomes smaller.
4. y-shift changes location, not parallaxMoving the object in Y shifts it up or down in both photos. In ideal vertical stereo it does not create y-parallax and it does not change x-parallax.
5. Differential parallaxCompare the absolute parallax of the object top with the absolute parallax of its bottom/base point. Their difference provides the stereo height signal used in the height-estimation equation.

Detailed derivation

xL,tf=X+B2H−h

Use similar triangles from the left exposure station to the top of the vertical object.

xR,tf=X−B2H−h

Use the same geometry from the right exposure station.

yL,t=yR,t=fYH−h

The y-shift control moves the object in cross-track direction. In ideal vertical stereo, both photos keep the same y coordinate, so ideal y-parallax is zero.

Pt=xL,t−xR,t=fBH−h

Subtract the two top-point x-coordinate equations. The X terms cancel, leaving the top absolute parallax.

Pb=fBH

For the bottom/base point, the elevation is zero relative to the reference datum, so its absolute parallax is Pb.

dP=Pt−Pb

This is the differential parallax: the difference between the absolute parallax of the top and the absolute parallax of the bottom.

Pt=Pb+dP

Once differential parallax is measured, the top-point absolute parallax can be written as the base-point parallax plus the parallax difference.

h=H·dPPt

From the ideal stereo relationship, height is proportional to the ratio between differential parallax and top absolute parallax.

h=H·dPPb+dP

Substitute the top-parallax relation from the previous step. This gives the practical height-estimation formula.

hH=dPPb+dP

This ratio form is useful for interpretation. It says height depends on how large the parallax difference is compared with the total top-point parallax.
